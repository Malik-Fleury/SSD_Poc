# Contexte du cours

- Cours : **Advanced Project Management** (Master).
- Consigne : choisir le projet d'un camarade, l'analyser, le faire avancer en **utilisant les outils de gestion de projet** (ex. charte projet, WBS, planning/Gantt, analyse des risques, parties prenantes, budget, business case…).
- Livrable final : un **rapport orienté investisseur** — il doit convaincre de mettre de l'argent dans le projet.

## Ce que le rapport doit faire ressortir

- Problème et opportunité (marché, durabilité, souveraineté des données en Suisse).
- Solution crédible techniquement (preuve par un prototype si possible).
- Chiffres : coûts (CAPEX/OPEX), revenus attendus, rentabilité, comparaison avec un datacenter classique.
- Risques identifiés **et** mesures de mitigation (montre la maturité du projet).
- Planning réaliste avec jalons.
